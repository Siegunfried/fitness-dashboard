## 二、有氧部分

### 核心原则

**心率区间：有氧极限心率的 60% ~ 80%**

| 参数 | 计算方式 |
|------|----------|
| 最大心率 | `220 − 年龄` |
| 有氧下限 | `最大心率 × 0.60` |
| 有氧上限 | `最大心率 × 0.80` |
| 燃脂区间 | `最大心率 × 0.65 ~ 0.75` |
| 心肺强化区间 | `最大心率 × 0.75 ~ 0.80` |

**持续时间：25 ~ 55 分钟**（不含热身和放松）

### 各阶段心率参考（以 19 岁为例）

```
最大心率 = 220 − 19 = 201 bpm

热身（5min）   →  < 120 bpm  (< 60%)
燃脂（核心）    →  120 ~ 150 bpm  (60% ~ 75%)
心肺强化（冲刺） →  150 ~ 160 bpm  (75% ~ 80%)
放松（5min）   →  逐渐降至 < 120 bpm
```

### 有氧训练类型

**稳态有氧 (LISS)**
- 心率维持在 60% ~ 70%
- 时长 40 ~ 55 分钟
- 项目：快走、慢跑、骑行、椭圆机

**变速有氧**
- 心率在 60% ~ 80% 之间波动
- 时长 25 ~ 35 分钟
- 模式：3min 低强度 + 2min 高强度，循环

**HIIT（每周 ≤ 2 次）**
- 心率冲击 75% ~ 80%
- 时长 20 ~ 25 分钟
- 模式：30s 冲刺 + 30s 休息，重复 10-15 轮

### 每周有氧安排

| 日期 | 类型 | 时长 | 心率区间 |
|------|------|------|----------|
| 周一 | 变速有氧 | 25-30 min | 60%-80% |
| 周三 | 稳态有氧 | 40-55 min | 60%-70% |
| 周五 | HIIT | 20-25 min | 75%-80% |
| 周六 | 低强度 | 30-45 min | 55%-65% |

> 有氧安排在力量训练之后，或与力量训练分开时段进行。

## 三、无氧部分

### 训练分化：推 / 拉 / 腿 / 上肢综合

**周一 — 推类（胸 + 肩前中束 + 三头）**

| 动作 | 组数 × 次数 | 目标肌群 |
|------|-------------|----------|
| 杠铃卧推 | 4 × 8-10 | 胸大肌 |
| 哑铃上斜卧推 | 3 × 10-12 | 上胸 |
| 哑铃肩推 | 3 × 10-12 | 三角肌前中束 |
| 侧平举 | 3 × 15-20 | 三角肌中束 |
| 双杠臂屈伸 | 3 × 8-12 | 胸 + 三头 |
| 绳索下压 | 3 × 12-15 | 三头肌 |

**周二 — 拉类（背 + 二头 + 后肩）**

| 动作 | 组数 × 次数 | 目标肌群 |
|------|-------------|----------|
| 硬拉 | 4 × 6-8 | 后链 + 背 |

| 面拉 | 3 × 15-20 | 后肩 + 肩袖 |
| 哑铃弯举 | 3 × 12-15 | 二头肌 |

**周四 — 腿部（股四 + 腘绳 + 臀 + 小腿）**

| 动作 | 组数 × 次数 | 目标肌群 |
|------|-------------|----------|
| 杠铃深蹲 | 4 × 8-10 | 股四头肌 |
| 罗马尼亚硬拉 | 3 × 10-12 | 腘绳肌 |
| 保加利亚分腿蹲 | 3 × 10 | 臀 + 股四 |
| 倒蹬机 | 3 × 12-15 | 股四头肌 |
| 坐姿腿弯举 | 3 × 12-15 | 腘绳肌 |
| 站姿提踵 | 4 × 15-20 | 小腿 |

**周五 — 上肢综合（推 + 拉复合）**

| 动作 | 组数 × 次数 | 目标肌群 |
|------|-------------|----------|
| 实力推举 | 4 × 6-8 | 肩 + 三头 |
| 负重引体向上 | 3 × 6-8 | 背 + 二头 |
| 哑铃卧推 | 3 × 8-10 | 胸 |
| 杠铃划船 | 3 × 8-10 | 背 |
| 阿诺德推举 | 3 × 10-12 | 肩 |
| 锤式弯举 | 3 × 12-15 | 二头 + 前臂 |

### 核心训练（周二 + 周四各 15min）

| 动作 | 组数 × 时长/次数 | 目标 |
|------|-------------------|------|
| 平板支撑 | 3 × 60s | 腹横肌 |
| 死虫式 | 3 × 15 每侧 | 腹直肌 |
| 悬垂举腿 | 3 × 12-15 | 下腹 |
| 俄罗斯转体 | 3 × 20 | 腹斜肌 |

### 力量训练守则

- 组间休息：复合动作 90-120s，孤立动作 45-60s
- 训练前热身 5-10min（动态拉伸 + 轻重量预热）
- 训练后拉伸 5-10min（目标肌群静态拉伸 2×30s）
- 渐进超负荷：每周增加 2.5%-5% 重量或 1-2 次重复
- 动作质量 > 重量

## 七、TodoList 填表格式（服务器解析规则）

编辑 `ToDoList.docx` 时遵循以下规则。服务器按缩进自动解析为壁纸每日任务。

### 解析规则

```
规则1：缩进 < 0.2cm  +  以「周一~周日」开头  →  天标题
规则2：缩进 ≥ 0.2cm  →  属于上方最近一天的任务项

被忽略的内容：
  · 空行
  · 以「─」开头的分隔线
  · 以「数据源」或「训练计划」开头的说明行
  · 单独出现的「TodoList」
```

### 正确格式

```
周一 — 力量训练（推）+ 有氧       ← 顶格，以周几开头
    热身（肩部绕环、弹力带激活）   ← Tab 缩进一次
    力量·推类（卧推 4×8-10 等）    ← Tab 缩进一次
    有氧运动（变速跑 25min）       ← Tab 缩进一次
    拉伸放松                      ← Tab 缩进一次
周二 — 力量训练（拉）+ 核心       ← 顶格
    热身（弹力带肩部热身 5min）
    ...
```

### 关键约束

| 规则 | 说明 |
|------|------|
| 天标题顶格 | `周一` 必须顶格（不缩进），后跟 `—` 标签 |
| 任务缩进一次 | 每个任务行按一次 Tab |
| `—` 前面是周几 | 标题必须从 `周一`~`周日` 开头 |
| 不跳级 | 任务不能出现在天标题之前 |

### 操作方式

```
加任务：当天最后一行按 Enter → Tab → 输入
加新天：当天最后一行按 Enter → Shift+Tab → 输入「周X — 标签」
改标签：直接编辑天标题行 `—` 后面的文字
```

### 常见错误

```
❌ 天标题缩进了 → 被当成任务，不识别为天
❌ 不以周几开头 → 被忽略
❌ 任务没缩进   → 和天标题同级，不归属任何天
```
